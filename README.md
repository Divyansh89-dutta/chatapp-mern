💬 Real-Time Chat App
This is a real-time chat application built using React for the frontend and Node.js with Socket.io on the backend. Messages are stored in a MongoDB Atlas database, allowing for persistent chat history.

🚀 Features
🔐 User Authentication (optional)

💬 Real-time messaging with Socket.io

📦 Message storage with MongoDB Atlas

💻 Frontend built with React

⚙️ Backend using Express + Node.js

🌐 Deployed on Render / Vercel (optional)

📁 Tech Stack
Frontend:

React

Axios

Socket.io-client

Tailwind CSS (if used)

Backend:

Node.js

Express

Socket.io

MongoDB (with Mongoose)
